# Атлас прикуса

Учебный интерактивный атлас зубочелюстных аномалий: последствия ротового дыхания и вредных привычек у подростков.

Статичный сайт без сборки: один файл `index.html` и папка `img/` с фотографиями.
Библиотеки подключаются с CDN (jsDelivr): Lenis, GSAP 3.13, three.js 0.160. Шрифты — Google Fonts.

## Структура

```
index.html   — весь сайт: разметка, стили и скрипты
img/         — фотографии (Wikimedia Commons, источники указаны на сайте)
.nojekyll    — чтобы GitHub Pages отдавал файлы как есть
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (файлы должны лежать в корне репозитория).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Свой домен

1. Settings → Pages → Custom domain → впишите домен (например, `atlas-prikusa.ru`) → Save. GitHub сам создаст файл `CNAME`.
2. У регистратора домена в DNS добавьте записи:
   - для домена без www — четыре записи **A**: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - для `www` — запись **CNAME** на `<логин>.github.io`.
3. Когда DNS обновится (от нескольких минут до суток), включите **Enforce HTTPS**.

## Лицензии изображений

Все фотографии взяты с Wikimedia Commons под свободными лицензиями (CC BY, CC BY-SA и др.); автор, лицензия и ссылка на источник указаны в подписи к каждому рисунку и в списке источников на сайте.

Материал носит образовательный характер и не заменяет консультацию врача.
